# Tic Tac Toe - Project Statement

## Problem Statement

Tic Tac Toe is a simple two-player game played on a 3 x 3 board. The purpose of this project is to create a Python program that allows two players to play the game through the terminal.

The program accepts the position selected by each player, checks whether the move is valid, updates the board and checks whether a player has won or the game has ended in a draw.

## Scope of the Project

The project is limited to a two-player, terminal-based Tic Tac Toe game.

The project includes:
- A 3 x 3 game board
- Two players using X and O
- Player input from positions 1 to 9
- Input validation
- Win checking
- Draw checking
- Score tracking
- Option to play another round

The project does not include a computer opponent or graphical interface.

## Target Users

The project is intended for students and users who want to play a simple two-player Tic Tac Toe game using Python.

## High-Level Features

1. Display the Tic Tac Toe board.
2. Accept moves from two players.
3. Check whether the entered position is valid.
4. Prevent a player from using an occupied position.
5. Check all possible winning combinations.
6. Detect a draw when all nine positions are filled.
7. Keep track of Player X wins, Player O wins and draws.
8. Allow the users to play another round.
